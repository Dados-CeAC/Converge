O que é CONVERGE?

CONVERGE é um portal centralizado que reúne todos os sistemas do Hospital das Clínicas da Faculdade de Medicina da USP (HC-FMUSP) em um único lugar, facilitando o acesso e a navegação.

Acesso Seguro

Autenticação com email corporativo @hc.fm.usp.br

Dashboard Intuitivo

Interface visual e organizada por categorias

Integração de Sistemas

Links para 30+ sistemas diferentes do HC

Responsivo

Funciona em desktop, tablet e mobile

Banco de Dados e Estrutura

Tabela Mãe vs Tabela Filha

Os dados são organizados em duas tabelas relacionadas:

📋 Tabela Mãe (tabela_mae)

Armazena 1 registro por CPF com dados resumidos:

cpf: "123.456.789-10"
matricula: "12345"
vinculo: "CLT"
situacao: "Ativo"
📚 Tabela Filha (tabela_filha)

Armazena múltiplos registros por CPF com dados detalhados:

seq_id: 1
cpf: "123.456.789-10"
grupo_generico: "Médico"
empresa: "HC-FMUSP"
filial: "Prédio A"
local_trab: "Clínica Médica"
cargo: "Médico Assistente"
funcao: "Clínico"

Por que Essa Estrutura?

Reduz Redundância

Dados comuns (CPF, matrícula) ficam na mãe

Histórico

Múltiplas posições/setores por pessoa

Performance

Buscas mais rápidas com índices

Flexibilidade

Buscar por CPF, situação, empresa

Índices de Busca

Buscar por CPF

Todos os colaboradores podem ser encontrados rapidamente pelo CPF:

// Busca rápida na tabela
ctx.db.query("tabela_mae").withIndex("by_cpf")
Filtrar por Situação

Buscar todos os colaboradores com status "Ativo", "Inativo", etc:

// Filtro por situação
ctx.db.query("tabela_filha").withIndex("by_situacao")

Query de Teste

A função buscarPrimeirosRegistros permite testar a conexão:

export const buscarPrimeirosRegistros = query({
  handler: async (ctx) => {
    const mae = await ctx.db.query("tabela_mae").take(5);
    const filha = await ctx.db.query("tabela_filha").take(5);
    return { mae, filha };
  }
})

Perguntas Frequentes

Como fazer login se esquecer a senha?

O CONVERGE usa autenticação via Clerk, que suporta:

  • OAuth com Google: Use sua conta Google corporativa
  • OAuth com Microsoft: Use sua conta Microsoft/Office365
  • Passkey: Biometria do seu dispositivo

Se esquecer a senha, clique em "Forgot password?" na tela de login para reset.

Posso acessar de celular?

Sim! O CONVERGE é totalmente responsivo. Funciona em:

  • 📱 Smartphones (iPhone, Android)
  • 📱 Tablets
  • 💻 Desktop

A interface se adapta automaticamente ao tamanho da tela. No mobile, o menu fica no topo como toggle.

O que fazer se um sistema não abrir?

Tente estas soluções:

  • Recarregar a página: F5 ou Ctrl+R
  • Limpar cache: Ctrl+Shift+Delete
  • Tentar outro navegador: Chrome, Firefox, Safari
  • Verificar conexão: Internet deve estar estável
  • Aguardar: O sistema pode estar em manutenção

Se o problema persistir, contate o suporte técnico.

Meus dados estão seguros?

Sim! O CONVERGE implementa várias camadas de segurança:

  • 🔒 Validação de Domínio: Apenas @hc.fm.usp.br
  • 🔐 Autenticação Clerk: Segurança de nível empresarial
  • 🛡️ Conexão HTTPS: Criptografia de dados em trânsito
  • 💾 Convex Database: Backup automático
  • 👁️ Acesso Controlado: Apenas quem pode, acessa
Posso personalizar meu perfil?

Atualmente, o CONVERGE exibe seus dados básicos do HC:

  • 👤 Nome completo
  • 📧 Email corporativo
  • 🏢 Departamento
  • 🎯 Função

Os dados vêm do banco de dados central do HC. Para atualizações, contacte RH.

Como funciona a Tabela Mãe e Filha?

Tabela Mãe: 1 registro com resumo de cada colaborador

CPF: 123.456.789-10
Matrícula: 12345
Situação: Ativo

Tabela Filha: Múltiplos registros com detalhes (cargo, setor, local)

CPF: 123.456.789-10 → Cargo: Médico (Prédio A)
CPF: 123.456.789-10 → Cargo: Supervisor (Prédio B)
CPF: 123.456.789-10 → Cargo: Pesquisador (Prédio C)

Isso permite histórico e múltiplas posições da mesma pessoa.
