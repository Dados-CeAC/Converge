Conhecendo a Interface

Topbar (Barra Superior)

O que você vê:

  • 🏥 Logo do HC-FMUSP - Identidade visual
  • 🏢 Logo CeAC - Centro de Análise de Dados
  • 👤 Seu Nome/Email - Identificação do usuário
  • 📱 Botão Menu - No mobile, expande/colapse o menu
  • 🔐 Logout - Sair do portal

Para quê serve: Identifica você, mostra informações rápidas e oferece navegação principal.

Sidebar (Menu Lateral)

Categorias Principais:

🏠 Home Dashboard principal com todos os sistemas
⚙️ Meus Sistemas Sistemas específicos para você
📋 Administrativo Funções administrativas e gestão
🏥 Assistencial Sistemas de atendimento ao paciente
🚑 Pronto Atendimento Sistemas específicos do PA
🛡️ Ocupacional Segurança e saúde no trabalho
📊 Indicadores Painéis e relatórios analíticos
👥 Colaboradores Dados e gestão de pessoal
Cards de Sistemas

Cada Card Contém:

  • 🎨 Ícone Visual - Identifica o tipo de sistema
  • 📝 Nome do Sistema - Título legível
  • ✨ Efeito Hover - Destacamento ao passar o mouse
  • 🔗 Link Clicável - Leva ao sistema quando clicado

Como usar: Simplesmente clique no card para abrir o sistema em uma nova aba!

✨ Interface Responsiva: O CONVERGE se adapta automaticamente para smartphone, tablet e desktop. No mobile, o menu fica oculto por padrão e pode ser aberto com o botão de menu na topbar.

Perguntas Frequentes

❓ Como faço login?

Use seu email corporativo @hc.fm.usp.br para fazer login. O sistema suporta OAuth com Google e Microsoft, além de Passkey (biometria).

❓ O site funciona no celular?

Sim! O CONVERGE é totalmente responsivo e funciona perfeitamente em smartphone, tablet e desktop. O menu se adapta automaticamente ao tamanho da tela.

❓ Meus dados estão seguros?

Absolutamente! Implementamos várias camadas de segurança: validação de domínio, autenticação Clerk, HTTPS, backup automático no Convex e controle de acesso.

❓ O que fazer se um sistema não abrir?

Tente: (1) Recarregar a página (F5), (2) Limpar cache (Ctrl+Shift+Delete), (3) Tentar outro navegador, (4) Verificar conexão de internet. Se persistir, contate o suporte técnico.

❓ Posso acessar os dados dos colaboradores?

Sim, dependendo de suas permissões. O CONVERGE integra dados do banco de dados do HC, mostrando informações como matrícula, cargo, setor, situação (ativo/inativo), etc.
