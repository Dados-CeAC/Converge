Como Usar o CONVERGE

Siga os passos abaixo para aprender a utilizar todos os recursos do portal de forma eficiente.

👤

Passo 1: Fazer Login

Acesse com seu email corporativo @hc.fm.usp.br na página de login do Converge. O sistema usa Clerk para autenticação segura.

🏠

Passo 2: Conhecer o Dashboard

Após login, você verá a interface principal com topbar (topo), sidebar (menu lateral) e grid de cards (área central)

📂

Passo 3: Explorar Menu

Clique nas categorias do menu lateral (Administrativo, Assistencial, Ocupacional, etc) para filtrar sistemas por área

🔗

Passo 4: Acessar Sistemas

Clique em qualquer card para abrir o sistema desejado. O Converge oferece acesso a mais de 30 sistemas integrados

👥

Passo 5: Ver Seu Perfil

Clique no seu nome no topbar ou acesse "Meu Perfil" no menu para visualizar seus dados e informações

📞

Passo 6: Abrir Tour Guiado

Clique no botão "Iniciar Tour" (se disponível) para receber uma explicação interativa de cada área do portal

💡 Dica Importante: O portal é totalmente responsivo! No mobile, o menu fica oculto por padrão e pode ser aberto com o botão de menu (≡) na topbar. Clique em "Iniciar Tour" no portal para receber uma explicação interativa de tudo.

Entenda Cada Parte da Interface

O Converge é organizado em 3 áreas principais. Clique para expandir e aprender detalhes sobre cada uma.

📍 Barra Superior (Topbar) - Identidade e Contexto

O que você vê aqui:

  • 🏥 Logo do HC-FMUSP - Identifica a instituição
  • 🏢 Logo CeAC - Centro de Análise de Dados do Hospital
  • 👤 Seu Nome/Email - Mostra quem está logado
  • 📱 Botão Menu (≡) - Em telas menores, expande/colapse o menu lateral
  • 🔐 Botão Logout - Sair de forma segura do portal

Para quê serve: A topbar fornece contexto visual, mostra sua identidade e oferece acesso rápido às funções principais de navegação e segurança.

Dica: A topbar sempre fica visível no topo, mesmo quando você rola a página para baixo.

📂 Menu Lateral - Centro da Navegação

Categorias de Sistemas Disponíveis:

🏠 Home Dashboard principal - Voltaraqui quando quiser ver todos os sistemas
⚙️ Meus Sistemas Sistemas específicos para a sua função/cargo
📋 Administrativo Gestão, contratos, suprimentos, faturamento, custos
🏥 Assistencial Atendimento ao paciente, consultas, linhas de cuidado

📊 Indicadores Painéis, relatórios, analytics e gestão de performance
👥 Colaboradores Dados de pessoal, gestores, gestão de RH
💼 Gestores Painéis e ferramentas para gestão de equipes
✓ Gestão da Qualidade Qualidade, conformidade e processos internos
📁 Dados Acesso a dados estruturados do hospital

Como usar: Clique em qualquer categoria para ver apenas os sistemas daquela área. Clique novamente em "Home" para voltar a ver todos os sistemas.

Dica Mobile: Em smartphones, o menu fica oculto por padrão. Clique no botão ≡ na topbar para abri-lo.

🎴 Cards de Sistemas - Acesso Rápido

O que há em cada Card:

  • 🎨 Ícone Visual - Identifica o tipo de sistema (médico, gestão, dados, etc)
  • 📝 Nome do Sistema - Título legível em português
  • ✨ Efeito Visual - O card muda ao passar o mouse, indicando que é clicável
  • 🔗 Link Direto - Abre o sistema em uma nova aba do navegador

Sistemas Disponíveis (30+):

HCMED, InterRad, Painel MV, SoulMV, MVPEP, MVGE, PIH, Intercon, Portal RH FFM, Natcorp, Linha de Cuidados, Programa de Rastreio, Controles Internos, Contratos, Suprimentos e Estoque, Faturamento, Custos, Comunicação, Apoio Predial, Farmácia, Hiperutilizadores, Saúde Ocupacional, Minhas Doses, Meu ASO, Meu Perfil, Meu Chamados, Ouvidoria, Votação CIPA, Agenda, Exame, e muitos outros.

Como usar: Simplesmente clique no card para abrir o sistema. Cada sistema abre em uma nova aba do navegador, então você não sai do Converge.

👤 Perfil do Usuário - Suas Informações

Onde Encontrar: Seu nome aparece no topo direito da topbar e também na sidebar.

O que você pode fazer:

  • 👁️ Ver seu nome e email de login
  • 📧 Consultar seu email corporativo @hc.fm.usp.br
  • 🔑 Acessar dados de identidade do sistema
  • 🚪 Fazer logout de forma segura

Como acessar "Meu Perfil": Clique em "Meu Perfil" no menu lateral ou nos cards para ver seus dados pessoais registrados no sistema.

🔐 Logout - Encerramento Seguro

O que é: Logout é o processo de sair do portal de forma segura e encerrar sua sessão.

Onde está: Botão "Logout" visível na topbar ou no menu de perfil.

Por que é importante:

  • 🔒 Encerra sua sessão autenticada
  • 🛡️ Protege seus dados pessoais e da instituição
  • 👥 Impede acesso não autorizado se você deixar o computador
  • ⏱️ Recomendado ao final do expediente

Dica de Segurança: Sempre faça logout antes de deixar seu computador, especialmente em ambientes compartilhados.

🖥️ Área Principal - O Painel de Trabalho

O que é: A área central é o coração do Converge - onde todos os cards de sistemas são exibidos.

Como funciona:

  • 📊 Mostra todos os sistemas quando você está na Home
  • 🔍 Filtra os sistemas de uma categoria quando você clica no menu lateral
  • 📱 Se adapta automaticamente ao tamanho da tela (responsive)
  • ⚡ Carrega os sistemas rapidamente

Layout em Grid: Os cards se organizam em uma grade que se ajusta conforme a largura da tela - em desktop são 3-4 cards por linha, em tablet são 2, e em mobile é 1.

✨ Interface Totalmente Responsiva: O CONVERGE se adapta automaticamente para smartphone, tablet e desktop. Você pode usar em qualquer dispositivo e o layout se ajustará perfeitamente!

Arquitetura e Status do Projeto

O Converge é uma plataforma moderna, construída com tecnologias de ponta. Conheça sua arquitetura, componentes e status de desenvolvimento.

Arquitetura Técnica

📦 Stack Tecnológico:

  • Frontend: HTML5, CSS3, Vanilla JavaScript (responsivo)
  • Backend: Convex (plataforma TypeScript reativa)
  • Banco de Dados: Convex DB (database reativo)
  • Autenticação: Clerk (OAuth + validação de domínio)
  • Ícones: Tabler Icons (CDN)
  • Hospedagem: Convex Cloud

Estrutura de Dados:

O Converge utiliza duas tabelas principais: Tabela Mãe (dados resumidos por CPF) e Tabela Filha (dados detalhados com múltiplos registros por colaborador). Essa arquitetura reduz redundância, permite histórico de posições e melhora performance em buscas.

Campos principais: CPF, Matrícula, Vínculo, Situação, Cargo, Função, Local de Trabalho, Empresa, Filial

Perguntas Frequentes

❓ Como faço login?

Use seu email corporativo @hc.fm.usp.br para fazer login. O sistema suporta OAuth com Google e Microsoft, além de Passkey (biometria).

❓ O site funciona no celular?

Sim! O CONVERGE é totalmente responsivo e funciona perfeitamente em smartphone, tablet e desktop. O menu se adapta automaticamente ao tamanho da tela.

❓ Meus dados estão seguros?

Absolutamente! Implementamos várias camadas de segurança: validação de domínio, autenticação Clerk, HTTPS, backup automático no Convex e controle de acesso.

❓ O que fazer se um sistema não abrir?

Tente: (1) Recarregar a página (F5), (2) Limpar cache (Ctrl+Shift+Delete), (3) Tentar outro navegador, (4) Verificar conexão de internet. Se persistir, contate o suporte técnico.

❓ Posso acessar os dados dos colaboradores?

Sim, dependendo de suas permissões. O CONVERGE integra dados do banco de dados do HC, mostrando informações como matrícula, cargo, setor, situação (ativo/inativo), etc.
